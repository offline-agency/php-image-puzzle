# @offline-agency/image-puzzle-player

Browser player and `<image-puzzle-player>` Web Component for game definitions
generated by the PHP package
[`offline-agency/image-puzzle`](https://github.com/offline-agency/php-image-puzzle).
It plays the sliding, swap, rotation, strips and jigsaw (rectangular,
hexagonal and triangular) modes with pointer, touch and keyboard input.
Gameplay runs on
[`@offline-agency/image-puzzle-engine`](../engine/README.md).

```html
<!-- Web Component -->
<script type="module">
  import '@offline-agency/image-puzzle-player/define';
</script>
<image-puzzle-player src="/puzzles/sliding.json" persist></image-puzzle-player>
<script>
  document.addEventListener('puzzle-complete', (event) => console.log(event.detail.moves));
</script>
```

```js
// Plain JavaScript
import { createPlayer } from '@offline-agency/image-puzzle-player';

const player = createPlayer(document.getElementById('puzzle'), { src: '/puzzles/jigsaw.json', locale: 'it' });
player.subscribe('complete', ({ moves, elapsedMs }) => console.log(moves, elapsedMs));
```

Without a bundler, use `dist/image-puzzle-player.iife.js` (global
`ImagePuzzle`) or `dist/image-puzzle-player.bundle.js` (one ES module). Both
register the element.

The full API (options, events, error codes, keyboard and pointer controls,
styling hooks, browser support) is in
[docs/PLAYER_API.md](../../docs/PLAYER_API.md). A working offline example is
in [`examples/player`](../../examples/player).
