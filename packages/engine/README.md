# @offline-agency/image-puzzle-engine

Headless rules engine for game definitions generated by the PHP package
[`offline-agency/image-puzzle`](https://github.com/offline-agency/php-image-puzzle).
It validates definitions and saved states, applies legal actions, tracks
moves/active time/hints, and supports undo/redo, reset, shuffle and
export/import. It has no DOM dependency; every player and framework adapter
in this repository delegates to it.

```js
import { createEngine } from '@offline-agency/image-puzzle-engine';

const engine = createEngine({ definition: await (await fetch('sliding.json')).json() });
engine.subscribe('complete', ({ moves, elapsedMs }) => console.log(moves, elapsedMs));
engine.dispatchAction(engine.legalActions()[0]);
const saved = engine.exportState();
```

Rules, randomness and state semantics are specified in
[docs/GAME_MODES.md](../../docs/GAME_MODES.md); the engine API, events and
error codes in [docs/PLAYER_API.md](../../docs/PLAYER_API.md). Conformance
with the PHP rules is enforced by the fixtures in `conformance/`.

Runtime: ES2022 plus `TextEncoder`, `structuredClone`, `queueMicrotask` and
timers (evergreen browsers, Node.js 18+).
