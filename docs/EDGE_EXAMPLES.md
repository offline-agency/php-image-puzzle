# Edge style examples

This page shows one sample piece for each built-in edge type. All examples use the same source image and a 2×2 grid. Images are generated by `examples/generate-edge-samples.php`.

## Config and factory

Edge style can be created from a JSON config with `EdgeStyleFactory`:

```php
use ImagePuzzle\EdgeStyle\EdgeStyleFactory;
use ImagePuzzle\PuzzleGenerator;

$config = json_decode(file_get_contents('config/edge-config.json'), true);
$edgeStyle = EdgeStyleFactory::fromArray($config);
$generator = new PuzzleGenerator($edgeStyle);
$puzzle = $generator->generateFromFile('photo.jpg', 4, 6);
```

Or from a file: `EdgeStyleFactory::fromFile('config/edge-config.json')`.

JSON schemas: [edge-config.schema.json](schemas/edge-config.schema.json), [puzzle-config.schema.json](schemas/puzzle-config.schema.json), [piece.schema.json](schemas/piece.schema.json).

## no_edge

No modification; piece image unchanged. Default when no edge style is passed.

**Config:**

```json
{ "edge": { "type": "no_edge" } }
```

**Example piece (top-left):**

![no_edge piece](images/edge-examples/no_edge/piece_0_0.png)

## line

Rectangular pieces with straight edges (no tab/socket). Same visual result as `no_edge`; use when you want a named “line” style.

**Config:**

```json
{ "edge": { "type": "line" } }
```

**Example piece:**

![line piece](images/edge-examples/line/piece_0_0.png)

---

## jigsaw

Classic jigsaw: ellipse-like tab/socket in the middle of each edge. Good default for a traditional puzzle look.

**Config:**

```json
{ "edge": { "type": "jigsaw" } }
```

**Example piece:**

![jigsaw piece](images/edge-examples/jigsaw/piece_0_0.png)

---

## arc

Arc-shaped tab/socket along each edge. Slightly narrower segment than jigsaw.

**Config:**

```json
{ "edge": { "type": "arc" } }
```

**Example piece:**

![arc piece](images/edge-examples/arc/piece_0_0.png)

---

## half_circle

Half-circle tab/socket on each edge. Diameter is half the edge length.

**Config:**

```json
{ "edge": { "type": "half_circle" } }
```

**Example piece:**

![half_circle piece](images/edge-examples/half_circle/piece_0_0.png)

---

## sinus

Sinusoidal (wavy) edge: the boundary follows a sine wave along each edge (two cycles per edge).

**Config:**

```json
{ "edge": { "type": "sinus" } }
```

**Example piece:**

![sinus piece](images/edge-examples/sinus/piece_0_0.png)

---

## rounded_corners

Rounds the four corners of each piece by making corner pixels transparent. Configurable radius.

**Config:**

```json
{
  "edge": {
    "type": "rounded_corners",
    "options": { "radius": 6 }
  }
}
```

**Example piece:**

![rounded_corners piece](images/edge-examples/rounded_corners/piece_0_0.png)

## Regenerating example images

From the project root:

```bash
php examples/generate-edge-samples.php
```

Optional arguments: `<input_image>` (default: `tests/fixtures/sample.png`), `<output_base_dir>` (default: `docs/images/edge-examples`).
