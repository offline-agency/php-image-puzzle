# CodeIgniter 4 example

Files to copy into a CodeIgniter 4 application: upload a photo, build a puzzle,
play it and keep validated progress. This is not a Composer package.

The walkthrough is in [docs/CODEIGNITER.md](../../docs/CODEIGNITER.md).
`tools/codeigniter/run.sh` verifies these files in a fresh `codeigniter4/appstarter`
application.
